# MmmDays

## 🌿 Общая идея

Минималистичное веб-приложение (PWA) для отслеживания менструального цикла. 
Название MmmDays.
ПРичем, важно, это должно быть профессиональное приложение,  а не макет. Им олжно быть приятно и максимально удобно пользоваться.

По умолчанию язык должен быть русский, но должна быть локализация на английский.

Фокус:
- приватность
- простота
- отсутствие перегруженности
- нейтральный, “незаметный” интерфейс

Работает пока без бэкенда, хочу чтоб оно хорошо удобно выглядело на телефоне.

---

## 🧠 Основные функции (MVP)

### 1. Календарь (только реальный а не выдуманный)
- по умолчанию отображение текущего месяца , но можно быстро и удобно скролить месяцы свайпом или на отдельные элемены влево-вправо.
- дни кликабельны
- состояния:
  - нет данных
  - скудно (light)
  - обильно (heavy)
Текущий день как-то помечается, но так чтоб не мешать отметке месячных, может рамочкой дополнительной.




### 2. Быстрое добавление
- цикл состояний по клику:
  - none → light → heavy → none

### 3. Статус (верхний блок)
- если идет:
  - `В процессе • N день`
- если нет:
  - `До начала: N дней`
- дополнительная строка:
  - `последний цикл: N дней`

считается по обильным дням.

---

### 4. Страница статистики

Чтоб было доступно, наглядно и красиво.

Отображает:
- последние (дата начала обильных)
- прогноз следующих
- средняя длина цикла
- средняя длительность
- регулярность (простая оценка)

Еще я бы хотела видеть график в виде столбчатой диаграммы например за последние 6 месяцев по умолчанию с выбором: 3 месяца, 6 месяцев, год. один столбик - 1 день. в нем высота воответствует долям 0,1,2 в зависимости от интенсивности.

## 💾 Хранение данных

### Режим 1 (MVP) — локальный
- `localStorage`
- без логина
- данные хранятся в браузере

#### Формат:

могу предположить такой

```json
{
  "2026-03-01": "light",
  "2026-03-02": "heavy"
}
```
но может ты что-то покомпактнее и удобнее предложишь
